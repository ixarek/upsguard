# Участие в разработке

- Тесты: `python -m unittest discover -s tests` (нужен Linux: используется `fcntl`).
- Программа только читает состояние ИБП и никогда не подаёт ему команд отключения выхода — это инвариант, его нельзя ослаблять.
- Решения об отключении принимаются только по свежим данным; при их отсутствии АРМ остаётся включённым.
- Изменения поведения сопровождайте тестом и правкой README.
